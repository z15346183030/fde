# 赵旭 — Forward Deployed Engineer

把 LLM 与数据系统落到客户生产环境的个人简历站。单文件、零依赖、无构建。

线上地址：https://z15346183030.github.io/fde/

## 这个站和普通简历站的区别

普通作品集讲「我做了什么」。FDE 岗位看的是另一件事：**你交付的东西能不能在客户现场活下来**。

所以整站围绕一条主线组织：

> 交付物不是能跑的 demo，而是可评测、可观测、可回滚、可迭代的系统。

## 结构

| 区块 | 内容 |
|---|---|
| Hero | 定位 + 一次部署流程的终端输出（含被评测闸门拦下的真实状态） |
| 01 现场 | 三个非标现场：企业大客户 / 工业产线 / 小 B 渠道，各自的原话、拆解、判断 |
| 02 链路 | 七段交付链路，每段可展开：在解决什么、具体动作、我的状态、常见坑 |
| 03 诊断台 | 交互组件：选场景出诊断卡 / 关键词检索语料库 |
| 04 项目 | 四个自建系统，按「问题 / 约束 / 做法 / 闸门」重写；下方接工具链：15 个零依赖工具 + 6 个长期项目，按「进场 → 交付 → 数据 → 闸门」的交付顺序分组 |
| 05 能力地图 | 四域 29 项，标注已交付 / 在做 / 下一步 |
| 06 路线 | P0–P3 补齐计划，每阶段有可验证产出 |
| 07 联系 | 发邮件菜单（QQ / 163 / 126 / Gmail / Outlook / 默认 / 复制） |

## 设计语言

- **生产环境控制台**：深色为默认，等宽标注，状态点语义色（绿=通过，琥珀=警告，灰=未做）
- **不重复上一版**：`portfolio` 仓库是浅色 Bento 版式；这一版是深色控制台版式，两站互不依赖
- **终端在浅色主题下保持深色**：作为首屏的视觉锚点

## 技术

- 单文件 `index.html`，无框架、无依赖、无外部字体
- 双主题（默认深色，快捷键 `T`），记忆选择
- 滚动进度、渐入动画、能力条动画
- 键盘可访问、`prefers-reduced-motion` 降级、`noscript` 兜底
- `Ctrl/Cmd + P` 自动切换单栏打印版式，可直接存 PDF
- Open Graph + JSON-LD `Person`

## 交互组件的实现

两个都是纯前端，不调任何模型：

- **diagnose**：4 个预置场景，每个是一份结构化诊断（SIGNAL / PROCESS / DATA / CUT / METRIC / RISK / GATE / FIRST），点击后逐行淡入
- **retrieve**：18 条语料，按关键词命中 + 字符重叠打分，返回 top 3 带 score。刻意做成「检索结果」的样子，而不是聊天框——因为 FDE 交付的检索层就该是可解释的

## 修改内容

所有文案都在 `index.html` 里：

- Hero 终端输出：搜索 `term-body`
- 三个现场案例：搜索 `class="cases"`
- 七段链路：搜索 `class="chain"`
- 诊断台数据：脚本里的 `var SCEN` 和 `var CORPUS`
- 项目卡片：搜索 `class="sys-grid"`
- 能力地图：搜索 `class="domains"`，状态由 `cap done` / `cap wip` / `cap next` 控制
- 学习路线：搜索 `class="road"`
- 配色：`<style>` 顶部的 `:root` 与 `html[data-theme="light"]`
